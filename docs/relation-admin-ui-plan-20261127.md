## 1. 程式核對結果（唯讀）

- 側欄（`src/lib/admin-shell-controller.ts` 第 5～23 行）的分類已經符合「依功能責任拆分」：
  - 「收藏」下的「收藏組合」連到 `/admin/bgg?view=relations&domain=collection`。
  - 「遊戲資料」下的「BGG 管理」連到 `/admin/bgg`，「遊戲關聯」連到 `/admin/bgg?view=relations`。
  - 選取狀態由 `currentAdminItem` 依 `view` 和 `domain` 判斷（第 46 行）。
- 三個入口共用 `src/pages/admin/bgg/index.astro`（56 行）：
  - 標題固定是「BGG 同步與關聯管理」（第 26 行），瀏覽器分頁標題也一樣。
  - 頁內三個切換按鈕（第 31 行）和側欄重複，而且沒有標出目前的分頁。
  - 規則說明有兩段（第 43～44 行），同時出現在遊戲關聯和收藏組合頁。
  - 新增表單（`RelationForm.astro`）、篩選（只能依單一來源或目標）和清單（每頁 20 筆，用游標分頁）都是展開的大區塊；封存按鈕直接放在每筆卡片上，用瀏覽器的 `confirm()` 確認。
- 使用者截圖中的 #263 → #262 是**收藏領域**的資料（`v2_collection_relations`），不是遊戲關聯。
- 兩種關聯的差別（`src/lib/relation-admin.ts`、`migrations/0022`）：

| 項目 | 遊戲關聯（`v2_game_relations`） | 收藏組合（`v2_collection_relations`） |
| --- | --- | --- |
| 端點 | `v2_games`（BGG 或 NotBGG 身分） | `v2_collection_items`（同一 `record_scope`） |
| 類型 | requires_base、expansion_of、standalone_related、same_series、integrates_with、**compilation_of**、accessory_for、other | 同左，但用 **bundle_contains** 取代 compilation_of |
| 來源 | manual 或 BGG；**BGG 原始關聯不能編輯或封存** | 全部是手動 |
| 確認狀態 | `admin_confirmed`（公開頁只顯示已確認） | 沒有 |
| 方向規則 | requires_base／expansion_of：來源要是擴充、目標要是本體或獨立遊戲；accessory_for：來源要是配件；compilation_of：來源要是合輯 | 同樣的規則，bundle_contains 的來源要是套組 |
| 循環 | 依賴類（requires_base、expansion_of、compilation_of、accessory_for）禁止循環；相關、同系列、整合遊玩允許循環 | 依賴類（含 bundle_contains）禁止循環，其餘允許 |
| 其他守衛 | NotBGG 與 BGG 已連結的身分不能互相建立關聯；不能和 `site_game_relations` 重複 | — |

## 3. 頁面情境契約（Q162）

由一個函式（例如 `relationPageContext(url)`）依現有參數決定，所有元件都用它的結果：

| 項目 | BGG 同步與快取 | 遊戲關聯管理 | 收藏組合管理 |
| --- | --- | --- | --- |
| 判定 | `view` 不是 `relations` | `view=relations`，`domain` 不是 `collection`（維持現有預設） | `view=relations&domain=collection` |
| 側欄分類 | 遊戲資料 | 遊戲資料 | 收藏 |
| 路徑提示 | 遊戲資料 / BGG 同步與快取 | 遊戲資料 / 遊戲關聯 | 收藏 / 收藏組合 |
| 頁面與分頁標題 | BGG 同步與快取 | 遊戲關聯管理 | 收藏組合管理 |
| 規則說明 | §4 的 BGG 欄 | §4 的遊戲關聯欄 | §4 的收藏組合欄 |
| 頁內切換按鈕 | 移除 | 移除 | 移除 |

既有網址、書籤、收藏詳細頁「管理收藏組合關係」的連結（`CollectionAdmin.astro` 第 30 行、`CollectionPurchasesPanel.astro` 第 53 行）都不變。

## 5. UI 設計規範 §15（候選，Q166）

NAV-01 導覽依操作目的分類；NAV-02 側欄名稱與頁面主要功能一致；NAV-03 頁面標題、路徑提示、選取狀態一致；NAV-04 不同業務責任有獨立入口；NAV-05 避免側欄與頁內分頁重複；NAV-06 共用程式元件不代表共用介面；NAV-07 桌面和手機的功能分類相同；NAV-08 調整導覽不得破壞既有連結和權限。

## 6. 版面（Q156～Q161，已採納）
