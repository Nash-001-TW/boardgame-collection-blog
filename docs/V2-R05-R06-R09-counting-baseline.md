## 日期粒度：方案C正式定稿

使用者已明確確認，納入NotBGG Admin Dashboard V2的R05／R06清點日期規格。

一次清點操作共用一個使用者選定日期，逐「副本×組件」保存本次確認數量與清點日期，以及系統儲存時間。只更新本次實際送出且確認成功的項目；未送出的組件與其他副本保持原日期。填了頁面日期不代表全部組件已確認；失敗／版本衝突不得留下部分新日期，日期仍在後端以台北日界驗證。

例：卡牌11/15、Token11/16，11/17只重清卡牌，只有卡牌變11/17；Token保持11/16。這不授權批次新增API或自動變更整盒完成日。
