# R11 第一版範圍與驗收

2026-11-17（Asia/Taipei）。使用者已確認身份C、議題6五項與三點補充；本文件整理本輪範圍草案與Codex確認。不代表功能已實作或測試通過，未授權部署或正式Migration。

## 第一版範圍

- 三平行分頁BGG資料／遊戲關聯／收藏組合，無參數固定BGG資料，有指定參數優先，分頁查詢互不污染，暫無角標。
- BGG本站搜尋不連外部，查看／同步分區；最多3不同ID、後端gate互斥、批內依序、間隔與冷卻。五種顯示狀態、成功／嘗試時間分開轉台北，首次失敗不宣稱保留舊成功資料。無逐筆進度／輪詢，未知結果不猜筆數不自動重送。獨立新增BGG資料並同步入口，失敗列不移除，不建遊戲身份收藏。
- 遊戲關聯手動可編、其他來源唯讀；八類、角色預覽與名稱搜尋、私人備註。新增預設未確認可當次確認；既有核心變更同次不可保持確認，備註不撤確認。manual封存／還原，還原未確認重驗；DB對稱有效manual防護、詳細衝突與版本冪等原子驗證。
- 跨表方案B：NotBGG配件關係唯讀可達原入口；R11／配件頁／NotBGG編輯三入口完全相同有效manual阻擋。公開方向資訊、投影句型與語意去重同步調整，不能只加去重鍵。
- 收藏組合主bundle_contains、其他次要；容器bundle，端點同正式／測試範圍未封存。依組合分頁、成員另取完整總數、一次一成員；有效直接成員／收藏封存成員／關係封存歷史分開，容器封存整組歷史。核心編輯與還原重驗，無公開確認。R04 source連結是兩端篩選，不自行當容器預填。

## 必要相依工作：列第一版、獨立工作項同波上線

- R03建立組合包採C：可連真實既有身份或獨立無game_id容器；收藏名稱必填，不改所連遊戲身份的類型，不建假NotBGG，不自動轉換既有36筆。
- R02／R04正常顯示無身份組合：收藏名稱、預設圖、無玩家等摘要用「—」、隱藏前往BGG，獨立組合不視為來源遺失異常。
- 預設不建副本／自動組件需求；純容器不需清點的儲存語意須核對P08。未確認儲存前不能只靠畫面排除統計或泛化所有實體bundle不需清點。
- 保持R10邊界：R03／R04不建改採購；新增收藏成功可帶正確收藏開R10。
- 獨立容器不新增公開身份入口，有身份沿用公開資格。須核對既有無身份組合公開列表行為，不因bundle自行公開／隱藏既有資料。
- R11導向R03後可返回並選取成功新建的組合，不丟原篩選與已填成員；帶入參數只作預填且後端驗資格，不接受任意返回URL。
- R02所屬組合標記仍是R02獨立需求，本波相依顯示工作不順帶擴成完整群組檢視。

## 第一版不含

批次加入成員、編輯bgg/import關係、合併關聯表、遞迴總成員、即時進度／輪詢、刪除失敗BGG空列、收藏關聯公開確認、R02所屬組合標記實作。新BGG快取如何取得正式身份入口仍待決，不能用容器C混充一般遊戲身份建立。
