## 2. 計算定義（依已採納規則整理，不需決策）

每個尺寸 S，只計 production 範圍、未封存收藏：

1. **待套用量**（SLV-04、SLV-05）：逐需求、逐適用副本計「需求張數－該需求在該副本的有效已套用量」，小於 0 視為異常；再按尺寸加總。指定副本的需求只計該副本；未指定的按適用副本展開（範圍見 Q52）。副本在藏、借出計入；售出、送出、遺失排除；狀態未知不納入確定需求。
2. **可用庫存**（SLV-02、PROD-02）：該尺寸**啟用**產品的帳面餘額（交易合計）加總；停用產品的餘額另列，不計可用。
3. **缺口**（SLV-06）：max(0，待套用量－可用庫存)。
4. **狀態**（SIZE-02、SIZE-03、SLV-08），依序判定：
   - **尚無產品**：有待套用量但沒有任何產品 → 庫存與缺口顯示「—」，不計入不足數。
   - **資料不完整**：該尺寸受下列任一影響（來源見 Q53）→ 庫存或缺口不得顯示充足或 0，顯示「—」並說明原因，不計入不足數。
   - **不足**：資料完整且缺口 > 0（含「有產品但全停用」、可用 0）。
   - **充足**：資料完整且缺口 = 0。
   - 無需求的尺寸不列狀態。
5. **同源**：尺寸頁、R01、卡套分頁提示都呼叫同一個伺服器端函式（新增 `src/lib/sleeve-shortage.ts`），不各自重算。查詢不得使用超過 4 段的複合 SELECT（D1 實測限制）。
6. **無法定位尺寸的歷史資料**（SIZE-03）：例如對應不到需求、也無法判定尺寸的歷史套用，不歸到任何尺寸，改在尺寸頁頂端另列「有 N 筆歷史資料無法判定影響哪個尺寸」，不能默認所有尺寸完整。
