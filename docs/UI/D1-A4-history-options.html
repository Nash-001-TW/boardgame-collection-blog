4. 固定規則（不需選）

資料來源與判讀

只讀 d1_quantity_history（0023 不可修改的回執），頁面伺服器端讀取，不新增 API、不寫入。每盒判讀用回執內的 evidence_json 快照，以和預覽相同的程式重算（把預覽裡「快照 → 判讀」的段落抽成共用函式），確保歷史和當時預覽的數字一致。

時間與操作者

時間以 Asia/Taipei 顯示月日時分，<time datetime> 保留完整時間。回執只存 Access 的帳號識別碼（不是 email）：與目前登入者相同顯示「你」，否則顯示「其他管理員（識別碼末 6 碼）」。（已修訂，DECISION_LOG D1-A4-ACTOR-01：一律顯示「管理員（識別碼末 6 碼）」）

缺資料與失敗

  • 快照中缺的欄位顯示「UNKNOWN」或「—」，不讀現值補。
  • 副本名稱：副本仍存在用目前名稱，並附快照的版本／語言；已不存在顯示「副本 #id（已移除）」。
  • 每張卡底部固定一行：「0023 套用前的預期量修改沒有紀錄（UNKNOWN）。」
  • 讀取失敗（例如正式環境尚未套用 0023）：只在歷史區顯示「更正歷史暫時無法取得」，不影響頁面其他部分。
  • 依收藏 ID 與組件 ID 讀取；回執的 record_scope 跟隨收藏本身，不另外篩選。
