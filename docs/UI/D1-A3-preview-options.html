Q8. 結果不明（UNKNOWN）時，這個組件還能再編輯嗎？

結果不明代表可能已寫入、也可能沒有。系統會保留操作識別，讓你用同一個識別查詢，不會換新識別重做。

A　建議

鎖住這個組件的數量編輯，直到得到確定結果

  • 避免在不知道 103 還是 100 的情況下又改一次。
  • 其他組件、清點照常可用。
  • 重新整理頁面後仍會顯示，並自動查詢一次。
  • 不會永久卡住：查詢仍不明時，可用同一個識別重新送出，冪等保證不會重複寫入。

查詢結果（quantity-status）

依回應的 outcome 走上面同一套顯示；查詢仍是 UNKNOWN 時維持鎖定，並出現「重新送出同一次更正」（見 Q8 A 第 2 步）。查詢請求的 4xx（授權、格式）不清除待處理操作，只顯示錯誤（HANDOFF 必修項）。同一時間只送一個請求。

無障礙

彈窗用原生 <dialog>＋aria-labelledby；開啟時焦點在標題、關閉後回到「預覽更正」鈕；結果訊息用 role=status／錯誤用 role=alert；狀態膠囊皆有文字，不只靠顏色。
