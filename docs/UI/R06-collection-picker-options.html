4. 固定規則（不需選）

  • 只在網址沒有 collection 參數、或參數找不到收藏時顯示搜尋；帶參數進入的行為不變。
  • 只顯示正式範圍（production）的收藏；測試範圍沿用收藏管理的 scope 參數，不在此頁切換。
  • 每頁最多 20 筆，沿用既有分頁游標；搜尋條件寫入網址（重新整理不遺失）。
  • 結果每列顯示名稱、收藏 ID、BGG／NotBGG 來源、狀態；整列可點，鍵盤可操作。
  • 原本的「收藏 ID」直接輸入保留在搜尋框（純數字依 Q28 處理），不另留兩個輸入框。
  • 查詢失敗顯示「暫時無法搜尋」，不顯示成「找不到」。
